# Easyhook Live Chat

Live Chat is a channel operated directly by Easyhook. You can install a chat
widget on a website or use Easyhook as the server for direct and group
conversations without deploying your own messaging backend.

## Two ways to use it

1. **Visitor widget:** create a widget in the portal, register its exact HTTPS
   origins, and publish the `eh_chat_pk_...` key in your frontend.
2. **Authenticated application users:** your backend creates a five-minute
   signed identity with `POST /v1/live-chat/identity-tokens`. The client receives
   a session limited to that identity and its conversations.

Never put a regular Easyhook API key or Supabase credentials in the browser.
The publishable key identifies a widget but does not grant access to the
organization.

## Capabilities

Live Chat supports text, images, video, audio, documents, stickers, replies,
forwarding, reactions, edits, deleted-message markers, read cursors, and typing
indicators. It also supports direct and group conversations. Messages appear
with `channel: "live_chat"` in the multichannel Inbox and normalized webhooks.

Sessions use short-lived access tokens and rotating, single-use refresh tokens.
The server validates the origin, membership, and action on every request.
Turnstile, independent rate limits, and Easyhook-generated identities protect
the anonymous bootstrap flow.

## Billing

Durable messages and actions consume wallet balance with idempotency. Reads,
state checks, and polling are free, so reconnecting or refreshing does not
duplicate charges. See exact payloads and errors in the
[full API reference](/api-reference#easyhook-live-chat).

## Widget language

The widget automatically detects the browser language and supports Spanish,
English, and Brazilian Portuguese. The snippet generated by the portal uses
`data-easyhook-language="auto"`. To force a language, change it to `es`, `en`,
or `pt-BR`:

```html
<script
  src="https://www.easyhook.dev/live-chat/easyhook-chat.js"
  data-easyhook-key="eh_chat_pk_..."
  data-easyhook-sitekey="..."
  data-easyhook-language="auto"
  async
></script>
```

The selected language controls buttons, notices, accessibility labels, dates,
and the security challenge. It never translates content written by visitors or
agents.
